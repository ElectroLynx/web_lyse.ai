# Framer Lyse AI v1

Projet de site / prototype réalisé avec une stack solide et orientée performance.

## Description

Ce dépôt contient une application frontend construite autour de SolidJS avec une structure pensée pour un rendu rapide, une ergonomie simple et une base facilement extensible.

## Stack technique

- SolidJS
- Vite
- TypeScript
- CSS / composants modulaires
- Architecture simple et maintenable

## Objectif

Créer une base de départ claire pour un projet Framer-like / marketing / produit, avec un rendu propre, une logique légère et une expérience de développement fluide.

## Structure du projet

- `src/` : code source de l’application
- `public/` : fichiers statiques
- `package.json` : dépendances et scripts
- `vite.config.*` : configuration Vite
- `.env` : configuration des secrets notemment pour le modèle utilisé de Lyse.AI

## Installation

```bash
npm install
```

## Démarrage

```bash
npm run dev
```

## Build de production

```bash
npm run build
```

## Prévisualisation de la build

```bash
npm run preview
```
